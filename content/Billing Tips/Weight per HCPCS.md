# _Weight per HCPCS_
## Manual Wheelchairs

| Patient Weight | HCPCS Code | Description                 |
| -------------- | ---------- | --------------------------- |
| ≤ 250 lb       | K0001      | Standard wheelchair         |
| 251–300 lb     | K0006      | Heavy Duty wheelchair       |
| 301 >          | K0007      | Extra Heavy Duty wheelchair |

---
## Walkers

| Patient Weight | HCPCS Code         | Description |
|----------------|--------------------|-------------|
| ≤ 300 lb       | E0143 / E0144      | Standard walker |
| 301–500 lb     | E0148 / E0149      | Heavy Duty walker |

## Commodes

| Patient Weight | HCPCS Code    | Description              |
| -------------- | ------------- | ------------------------ |
| ≤ 300 lb       | E0163 / E0165 | Standard commode         |
| 301–450 lb     | E0167         | Heavy Duty commode       |
